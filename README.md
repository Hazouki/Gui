# HouseRules

HouseRules helps people who share an apartment make everyday expectations clear, fair and mutually understood.

## The problem
Roommates, especially newcomers, often struggle to coordinate daily routines because many household expectations stay unspoken. Different assumptions about cleaning, noise, guests, food, privacy and shared costs lead to confusion and recurring tension.

## Design goal
Roommates understand one another's expectations and feel confident that everyday shared living arrangements are clear, fair and mutually understood.

## Research background
Built from Week 3 and 4 findings (context mapping, secondary research, user interviews):
- New residents hesitate to ask questions because they don't want to seem difficult.
- "Clean" and "quiet" mean different things to different people.
- Rules are often learned only after someone gets annoyed.
- Residents prefer fair, flexible agreements over strict rules.

## Features
- Join or create a household with an invite code
- House rules by category with status (Agreed / Being discussed / Not set)
- Plain-language rules with practical examples
- Suggest changes and vote on them
- First-week checklist for new roommates
- Preference comparison showing where roommates differ
- Anonymous "Ask the household" questions
- Shared chores schedule

## Usability
Designed around Nielsen's heuristics: status feedback (toasts), inline validation, help icons beside inputs, undo, and consistent, plain language. Built with accessibility in mind (WCAG AA).

## Tech stack
React, Vite, TypeScript, Tailwind CSS. Demo data is stored in localStorage.
